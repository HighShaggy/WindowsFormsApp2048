# 🎮 **2048 — на WindowsForms**  
 
Моя реализация на **C# (Windows Forms)** сохраняет все особенности оригинальной игры и добавляет удобное управление, подсчёт очков и сохранение рекордов.  

## 🔥 **Особенности**  
✔ **Классические правила** — соединяйте плитки с одинаковыми числами (2→4→8→...→2048)  
✔ **Система очков** — чем больше число, тем выше счёт  
✔ **Лучший рекорд** — автоматическое сохранение максимального результата  
✔ **Рестарт игры** — начать заново в любой момент  
✔ **Проверка победы/поражения** — уведомления при достижении 2048 или проигрыше  
✔ **Управление** — стрелками или **WASD**  

## ⚙ **Технологии и реализация**  
- **C# и .NET Framework** (Windows Forms)  
- **ООП** (классы для игры, логики и интерфейса)  
- **Сохранение данных** (рекорд в файле/реестре)  
- **Обработка клавиатуры** (плавное управление)
